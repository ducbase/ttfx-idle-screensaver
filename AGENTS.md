## Pull requests and release notes

GitHub-generated release notes list merged PR titles. Every PR title must be a short,
user-facing change statement in imperative style:

- `Fix screensaver exiting after disable`
- `Add always-on-top screensaver window`
- `Document custom artwork paths`

Avoid implementation-only titles (`refactor`, `wip`, `fix stuff`), issue-only titles,
and commit hashes. PR descriptions may hold technical detail; they are not release notes.
